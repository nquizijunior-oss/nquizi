# Nkenglefac Nquizi Junior — Personal Portfolio

A responsive, category-based portfolio built with HTML, CSS and vanilla JavaScript.

## Pages
- `index.html` — Home
- `work.html` — Work overview and categories
- `work/brand-identity.html` — Brand identity projects
- `work/social-media-design.html` — Social media design projects
- `work/advertising-campaigns.html` — Advertising and campaign projects
- `work/print-outdoor-design.html` — Print and outdoor design projects
- `services.html` — Services
- `about.html` — About and experience
- `contact.html` — Contact details and email enquiry form

## Run locally
Open `index.html` in a browser. For best results, use a local static server (for example, VS Code Live Server). The site uses Google Fonts when an internet connection is available and falls back to system fonts otherwise.

## Contact form
The contact form prepares an email using the visitor's default email application. It does not send or store form submissions on a server.

## Portfolio assets
Images are organised by category under `assets/images/`. Original supplied project artwork has been retained.


## Downloadable CV
The PDF CV is stored at `assets/cv/Nkenglefac_Nquizi_Junior_CV.pdf`. Download links are available in the homepage hero and About page. The original PDF content and layout have been kept unchanged.
